# Python-Webscraping-Weekly-Weather
This is a simple web scraping project/practice. Python with BeautifulSoup was used to scrape the 7 day forecast summary off of a weather platform. The 7 day forecast data was converted into a dictionary and used to create a Pandas DataFrame. This was then exported into an excel file (Weather_forecast.xslx). 

I used Jupyter Notebook to do the initial coding and saved as a .ipynb file. 
Then wrote a plain python script as well and saved as a .py file. 
All of the mentioned files are uploaded to the repository. 

I also included Weather_forcast_graphics.xslx as a practice with nesting If functions in excel to change graphics based on weather.
